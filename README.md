# 🌐 Nairo Frontend

A modern social networking platform built with **React**, **TypeScript**, and **Vite**, focused on performance, user experience, and scalability.

## 🔗 Links

- 🌍 **Live Demo:** https://nairo-frontend-production.up.railway.app/

## ✨ Features

- 🔐 Authentication & Authorization
  - Registration
  - Login
  - OTP email verification
  - Password recovery
  - Secure authentication with cookies

- 👤 User Profiles
  - Edit profile information
  - Upload avatar
  - Bio support
  - Follow / Unfollow users
  - User search

- 📝 Posts
  - Create posts with images
  - View post details
  - Comments
  - Save posts
  - Responsive post cards

- 💬 Real-Time Chat
  - Private conversations
  - Typing indicator
  - Automatic scroll to latest messages
  - Chat search
  - Delete chats

- 🌍 Internationalization (i18n)
  - Multi-language support
  - Ukrainian
  - English
  - Polish
  - Turkish
  - Italian
  - Portuguese
  - Japanese
  - French
  - German
  - Spanish
  - Easy to add new languages

- 🎨 Themes
  - Light Mode
  - Dark Mode

- 📱 Responsive Design
  - Mobile-first approach
  - Tablet support
  - Desktop optimization
  - Ultra-wide screen support

- ⚡ Performance
  - Lazy loading
  - Optimized images
  - Infinite scrolling
  - Efficient rendering

- 😊 UI/UX
  - Smooth animations with Framer Motion
  - Emoji picker
  - Beautiful loading states
  - Custom scrollbars
